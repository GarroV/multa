# Design — эталон

`prototype.html` — исполняемый макет из Claude Design, **источник визуальной правды** для веба,
мобильного, бота, онбординга и лендинга. Открывается файлом в любом браузере (self-contained бандл,
шрифты внутри). Версия от 31.07.2026 заменила первый эталон от 19.07; предыдущая лежит в истории git.

Поверхности переключаются кнопками сверху, там же тумблеры темы (DARK / LIGHT) и языка (EN / RU).
Словарь токенов и правила — `docs/06-design-system.md`.

## Что в макете есть, а в бэкенде пока нет

Полная карта покрытия и отдельные задачи — issue #44. Кратко: счета и остатки, совместный доступ,
мастер-режим по периодам, фиксация курса при поступлении, расширенные настройки, сигналы как
сущность, категорийная аналитика, откат ревизий, провайдер размена, заморозка цели, новые правила
повтора.

## Чего в макете нет, но терять нельзя

Экран ревью раскладки чека, форма факта размена в вебе, замочек защищённой категории и архивация,
CRUD валютных корзин. Всё это уже поддержано API и обязано появиться при вёрстке (issue #44).

## Известное расхождение с кодом

`--dim` в макете (`#55648A` тёмная, `#7E8DA8` светлая) даёт контраст 3.4 при 9–11px — ниже WCAG AA.
В коде значения затемнены/осветлены до 5.03 и 5.44 (`docs/06-design-system.md`, сноска к таблице
токенов). При следующем обновлении макета имеет смысл поправить это и в нём.

## Как пользоваться

Сверяться визуально с макетом, токены брать из `docs/06-design-system.md`. Код из бандла не
переносится дословно (это DC-компонент с встроенным состоянием, не React-приложение): экраны
переписываются на React + Tailwind по токенам, а данные приходят из API, а не из локального состояния.

\* Тарифы на лендинге — заглушка: биллинг в MVP не строится (dogfooding-first, `docs/07-roadmap.md`),
цифры не являются зафиксированным решением.
