# Design — эталон

`prototype.html` — интерактивный макет из Claude Desktop, **источник визуальной правды** для веба, мобайла, бота, онбординга и лендинга. Открывается в любом браузере (self-contained бандл). 5 поверхностей переключаются вкладками сверху, есть тумблер EN/RU.

Дизайн-язык — «Neon Ledger» (полные токены: `docs/06-design-system.md`).

## Поверхности в макете

| Вкладка | Экран | Ключевое |
|---|---|---|
| Web app | Дашборд (десктоп) | Герой-цифра `₽3,412/day`, сигнал-баннер, блок «To exchange», бары категорий (Food в риске), таймлайн прогноза, карточки долг/конверт/цель |
| Mobile | «Сегодня» (390px) | Одна колонка, watch list, компактный exchange, FAB «+», таб-бар Today/Plan/Exchange/Goals |
| Bot | Telegram-чат | Карточки ввода/сигнала/чека, чипы команд, аннотации формата сообщений |
| Onboarding | Степпер (5 шагов) | Шаг 1 — базовая валюта; back/skip/next |
| Landing | Маркетинг | «Get fined. In a good way.», the pain, 3 фичи, pricing*, FAQ |

## Расхождения с docs/ (устранять по мере реализации)

- **Шрифт UI — Geist** (в макете), тогда как `docs/06-design-system.md` называл Inter. Канон теперь — **Geist** (UI) + JetBrains Mono (деньги/цифры) + Space Grotesk (герой/бренд/логотип). `docs/06` обновлён.
- **\*Pricing на лендинге — заглушка.** Биллинг в MVP не строится (dogfooding-first, см. `docs/07-roadmap.md`), а `docs/14-critical-review.md` возражает против лимита валют во Free. Тарифные цифры на лендинге не являются зафиксированным решением.

## Как пользоваться

При реализации экранов — сверяться с этим макетом визуально, брать токены из `docs/06-design-system.md`. Точный код из бандла не извлекается (минифицированный React) — переписываем на React + Tailwind по токенам.
