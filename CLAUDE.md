# CLAUDE.md — инструкция для Claude Code (имплементация Multa)

Ты строишь Multa — помощник по распределению денег для живущих между валютами. Вся правда — в docs/. Порядок чтения: 00-vision → 01-domain-model → 02-data-schema → 03-architecture → 04-web-ux → 06-design-system → 07-roadmap. Работай по спринтам из 07-roadmap, не перепрыгивай.

**Бюджет инфраструктуры: $0 + один OpenAI-ключ.** Ни одного платного сервиса/хостинга (см. 03-architecture §Профиль нулевой стоимости): бот — long polling (не webhook), доступ — Tailscale (не домен), auth — пароль+TOTP/Telegram Login (без email-провайдера), мониторинг self-hosted. Единственное исключение — OpenAI API (ключ у основателя, env `OPENAI_API_KEY`): vision-фоллбек чеков (gpt-4o-mini, structured output) и позже Whisper. QR-путь чеков всегда пробуется первым — он бесплатный. Других платных SaaS не подключать, других ключей не просить.

**Режим: dogfooding-first (см. шапку 07-roadmap).** Первый пользователь — основатель; DoD MVP — он ведет свой бюджет в Multa вместо Excel. Биллинг/админку/тарифы НЕ строить до явной команды. Из доков 08 (биллинг) и 09 (админка) на этапе MVP — ничего; 10 (правовое) — только когда появятся сторонние пользователи. При конфликте объема и скорости — выбирай скорость: фичи из доков не пропадут, они дождутся своей фазы.

## Железные правила

1. **Деньги — только integer minor units** (bigint/number). Float в денежных значениях = баг. Хелперы в packages/core/money.ts.
2. **Курс — иммутабельный снапшот** в транзакции (rate, rate_source, rate_date, base_amount_minor). История никогда не пересчитывается.
3. **Каскад приоритетов** (раздача): debts → buckets → envelopes → categories → goals. **Сжатие при нехватке**: цели → конверты → категории (решение основателя 2026-07-19; совпадает с 01-domain-model §Исполнение). Долги и валютные корзины автоматика не трогает никогда; защищённые категории не режутся автоматически (только явным выбором пользователя).
4. **Никакой доменной логики в компонентах React** — только packages/core (чистые функции) и apps/api.
5. **Все строки UI — через i18n-ключи** (packages/i18n, ru + en). Хардкод строк — баг.
6. **Цвета — только семантические CSS-переменные** из 06-design-system. Хардкод hex — баг.
7. **Изоляция workspace — в API-middleware.** Ни один хендлер не принимает workspace_id от клиента; скоуп только из токена. Клиент в БД напрямую не ходит никогда.
8. **Тесты**: packages/core — обязательно (vitest, включая инварианты из 01-domain-model §Инварианты); api — на каскад, пересборку, fx-фоллбеки.
9. Тон текстов: штурман, не учитель. Без «Вы превысили!», без вины (примеры в 06-design-system §Тон).

## Стек (зафиксирован, не менять без обсуждения)

pnpm + Turborepo; apps/web (Vite + React + TS + TanStack Router/Query + Tailwind), apps/api (Node 22 + Hono + Drizzle + better-auth), Postgres 16 — всё self-hosted через docker-compose (postgres + api + caddy), без BaaS. Бот (фаза 2): grammY + webhook. AI: Gemini Flash / Claude Haiku через API, structured output, только с сервера.

## Конвенции

- TS strict, ESM everywhere. Zod-схемы на границах API.
- Миграции — только через supabase/migrations, имена `NNNN_verb_noun.sql`.
- Коммиты: conventional (`feat(core): cascade compression`), маленькие PR-ы по одной фиче спринта.
- Ключи i18n: `area.screen.element` (`plan.rebalance.title`).
- Компоненты: src/components/ui (дизайн-система) отдельно от фичевых.

## Референс-данные

В `reference-data/` лежат две реальные таблицы основателя (описаны в docs/00-vision.md): «Кетчуп в Химках.xlsx» — эталон планирования по полумесяцам (структуру должен уметь импортировать Excel-мигратор); «Финмодель основная.xlsx» — 5000+ реальных позиций с разметкой по категориям и листом «Словарь» — тестовый датасет для автокатегоризации и приемочные данные для импорта «журнала позиций». Использовать для тестов; наружу не коммитить (приватные данные — в .gitignore).

## Известные грабли

- ЦБ РФ XML: windows-1251, значения с запятой («79,4567»), поле Nominal (JPY за 100), курс публикуется накануне «на завтра».
- Выходные: курса нет → брать последний рабочий день, rate_date = фактическая дата котировки.
- Кросс-курсы вычислять из котировок к базе источника, не хранить.
- JPY/KRW exponent 0, BHD/KWD 3 — см. money.ts, не хардкодить «÷100».
- Telegram initData: проверять HMAC на сервере (secret = bot token), не доверять клиенту.

## Definition of Done спринта

Типы зеленые, тесты зеленые, фича работает в деве на реальном Supabase, строки в ru+en, соответствие дизайн-токенам, DoD-пункт из 07-roadmap выполнен буквально.
