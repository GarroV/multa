# Multa — Подписки и биллинг

> **Статус (решение основателя, 2026-07-19): весь биллинг отложен, в MVP не строится ничего.** Направление на будущее: подписка через App Store (и Google Play). Это требует нативной оболочки — веб оборачивается в Capacitor, IAP подключается через RevenueCat (один SDK: App Store + Google Play + Stripe-web, entitlements сходятся в одном месте, наш API спрашивает статус у RevenueCat). Комиссия сторов 15–30%, зато налоги/возвраты/доверие — на Apple/Google. Всё ниже — проектировка на этот момент, не задача сейчас.

## Провайдеры платежей

- **Stripe** — глобальная карта, подписки, вебхуки. Основной.
- **Telegram Stars** — оплата из РФ без Visa/MC. Инвойс из бота/Mini App, цена в Stars из plan_prices, продление вручную-повторяемым платежом (Stars не умеет автопродление карт — подписка со сроком, бот напоминает).
- **Manual/comp** — админка выдает подписку руками: бета-тестеры, инфлюенсеры, возвраты.
- ЮKassa — кандидат, если Stars не хватит для РФ. Не в MVP.

## Жизненный цикл подписки

`trialing → active → past_due → canceled/expired`, отдельно `lifetime`.

- Триал Pro 14 дней без карты при регистрации (полный Pro, потом мягкая деградация в Free).
- **Деградация без потери данных**: превышение лимитов Free (валюты/счета) переводит лишние сущности в read-only, ничего не удаляется никогда.
- past_due: 7 дней grace с ретраями Stripe, письма-напоминания без агрессии (тон штурмана).
- Отмена — одной кнопкой в настройках, действует до конца оплаченного периода. Без dark patterns: это часть бренда.
- Возврат: 30 дней без вопросов (аргумент доверия на лендинге).

## Техника

- `plans`, `plan_prices`, `subscriptions`, `payments`, `ai_usage` — см. 02-data-schema §Billing.
- **Entitlements резолвятся только на сервере**: middleware `requireEntitlement('exchange_planner')`; клиент получает снапшот entitlements в /me и лишь прячет UI.
- Stripe-вебхуки: идемпотентность по event id, подпись обязательна; статус подписки — единственный источник правды, никаких «локальных» продлений.
- AI-лимиты: счетчик `ai_usage` (workspace, месяц) инкрементится в API перед вызовом модели; превышение — мягкий апселл, QR-путь остается бесплатным всегда.
- Все суммы платежей — bigint minor units (как везде).
