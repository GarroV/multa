## Как начать разработку

1. Скопировать папку в корень нового репозитория как `docs/`, CLAUDE.md — в корень.
2. Открыть в VS Code с Claude Code, сказать: «Прочитай CLAUDE.md и docs/, начинай Спринт 1 из docs/07-roadmap.md».
3. Понадобятся: Docker на сервере/машине разработки, позже — API-ключ Gemini/Anthropic (спринт 5), токен бота от @BotFather (фаза 2). Всё self-hosted, внешних аккаунтов не нужно.

## Ключевые решения (зафиксированы с основателем)

- План крупными мазками по периодам выплат; каждый кофе не записываем никогда.
- Каскад: долги → корзины → конверты → категории → цели; сжатие наоборот; долги неприкосновенны.
- Зарплата раскладывается по валютным корзинам; фактический курс размена фиксируется, спред копится в аналитике.
- Чеки: QR (ФНС РФ, Сербия) → бесплатно и точно; фото → vision-LLM; не распознано → «Общее».
- Пересборка плана запоминается (PlanRevision) и учится на решениях пользователя.
- Деньги в minor units, курсы — иммутабельные снапшоты.
