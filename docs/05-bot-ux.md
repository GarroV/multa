# Multa — UX Telegram-бота (фаза 2)

Роль: бот пишет и сигналит, веб думает. Никакой аналитики длиннее 5 строк в чате. Привязка: Telegram Login на сайте или deep-link из бота → маппинг на workspace.

## Ввод

- Свободный текст: «250 еда», «кофе 4.5 eur вчера», «grab 350 rsd» → запись создана, ответ одной строкой: «✅ Еда −250 RSD (≈212 ₽) · Еда: 15.2k/20k». Валюта по умолчанию — из последнего ввода.
- Молчание = подтверждение. Инлайн-кнопки под ответом: [категория] [валюта] [дата] [удалить].
- Фото чека → QR/vision пайплайн → «Чек Maxi 2 340 RSD: Еда 1 900, Ребенок 440. Ок?» [ок] [все в Общее] [разобрать в вебе].
- Голосовое → Whisper → тот же пайплайн.
- Несколько строк одним сообщением = несколько записей.
- Пины: `/кофе` — привычная сумма одним словом.

## Дайджесты и сигналы (все отключаемы по отдельности)

- **День выплаты** (главный), в два шага. Шаг 1 — подтверждение прихода: «Ожидали 133 980 ₽ — пришло столько?» [да] [другая сумма]; при другой сумме каскад пересобирается и дайджест обновляется. Шаг 2 — раскладка с кнопками под каждым пунктом: «Сбер 20k · размен 60k→EUR · инвестиции 8k · на жизнь 1 870/день до 25-го» [Сбер оплатил] [Размен сделан] [Инвестиции отложил] [Позже]. «Размен сделан» спрашивает фактически полученную сумму → курс и спред. Всё вручную по умолчанию (авто — опция в настройках пункта). Неподтвержденное напоминается один раз через 2 дня, без нытья.
- Burn-rate сигнал: «Еда: 18k из 20k, осталось 6 дней. Пересобрать?» [из Прочего +3k] [из конверта] [в вебе].
- Утро (опц.): «Сегодня доступно 1 870 ₽ · вчера −2 340».
- Закрытие долга: «Озон погашен 🎉 Освободилось 8k/период. Куда?» [цель] [конверт] [на жизнь].
- Восстановление: молчание 3+ дней → «Введи примерно одной суммой, и едем дальше» (без стыда).

## Команды

`/plan` — план текущего периода одной карточкой; `/rate` — мои курсы на сегодня; `/exchange 60000` — записать размен (спросит фактически полученную сумму, посчитает курс и спред); `/goal` — прогресс целей; `/mute` — тишина.

## Mini App

Тап по любой карточке бота → Mini App (тот же веб-код, авторизация initData): мини-дашборд, ревью чека, пересборка плана. Без выхода из Telegram.
