# Multa — UX веб-приложения (первая поверхность)

Принцип: каждый экран отвечает на вопрос, а не показывает данные. Ноль таблиц на главном экране.

## Онбординг (цель: ага-момент < 2 минут)

1. Базовая валюта (одна кнопка из популярных + поиск).
2. «Когда приходят деньги?» — два блока. Сначала **ритм планирования**: два раза в месяц (числа редактируемые), раз в месяц N-го, цикл в N недель от реальной даты выплаты — у каждого варианта превью ближайших дат, которые реально сгенерит планировщик, плюс правило переноса выплаты с выходного. Затем **сколько приходит**: список выплат (метка · число · сумма или % от оклада), предзаполненный числами ритма; если в день начала периода ничего не приходит — мягкое предупреждение, не блокировка. Источников может быть несколько (подработка, разовый гонорар, «когда как») — доход периода складывается из их приходов, а границы периодов задаёт только ритм.
3. Обязательства: «Платишь кредиты/рассрочки?» → быстрое добавление долгов (имя, платеж, когда закончится). Пропускаемо.
4. «Тратишь в другой валюте?» → создание валютных корзин (аренда EUR...). Пропускаемо.
5. Система сама собирает первый план периода каскадом из пресет-категорий → **ага-момент: экран «Твой план до 25-го: жить на X/день, поменять Y в EUR, к концу месяца свободно Z»**.

Категории не настраиваются на онбординге. Импорт истории — потом.

**Онбординг пропускаем целиком** — кнопка «пропустить настройку» есть на каждом шаге. Тогда воркспейс создаётся с дефолтами (валюта RUB, ритм 10/25, выплата в предшествующий рабочий день), доход остаётся пустым, а «План» показывает честный чистый лист с дорогой в настройки — не «что-то пошло не так». Источник дохода добавляется там же в настройках, и план собирается сам. Флаг пропуска живёт на сервере (`workspaces.onboarding_skipped`), поэтому с другого устройства онбординг не спрашивает заново.

## Главный экран (Dashboard)

Сверху вниз:

1. **Герой-цифра**: «Можно тратить N/день до выплаты (осталось D дней)» — в базовой валюте, крупно, моноширинно.
2. Строка статуса: «Свободно всего: X» → клик = разложение по счетам/валютам.
3. **Блок «К размену»**: «С выплаты 25-го: 60k RUB → EUR, 40k → RSD» + кнопка «размен сделан» (ввод фактических сумм → авто-курс и спред).
4. **Категории периода**: горизонтальные прогресс-бары план/факт; у категории с burn-rate риском — неоновый маркер и «хватит до 21-го» + кнопка «Пересобрать».
5. **Лента прогноза**: таймлайн до конца горизонта — выплаты, крупные платежи, окончания долгов («Озон закрывается в марте»), риски целей.
6. Цели и конверты: прогресс + «4,5 зарплаты до мотоцикла».

## Чеклист дня выплаты

В день выплаты дашборд открывается экраном «Раскладка». Первый шаг — подтверждение прихода: «Ожидали 133 980 — пришло столько?»; другая сумма → каскад пересобирается от факта (цели → конверты → категории, долги и корзины неприкосновенны), разница подсвечена. Дальше список плановых движений (долги → размен → конверты → цели) с кнопкой «сделал» у каждого — по умолчанию всё подтверждается вручную, включая платежи по кредитам (их тоже переводят руками). Бейдж «авто» — только если пользователь сам пометил пункт как автосписание. Частичное исполнение — тап по сумме, ввод фактической, остаток: [перенести на следующий период] [отпустить в свободные]. Неподтвержденные пункты остаются мягко подсвеченными в дашборде до конца периода; закрытие всех пунктов — маленький celebration («курс проложен»).

## Ввод (глобальная кнопка «+», всегда на экране)

Одно поле «умного ввода» + альтернативы:

- Текст: «250 еда», «кофе 4.5 eur вчера» → парсер, категория предзаполнена, подтверждение Enter.
- Сумма кнопками: сумма → категория (сетка иконок) → готово. 3 клика.
- Чек: drag&drop/фото → QR-детект на клиенте (jsQR) → позиции по статьям на ревью-экране; «не разбирать» = вся сумма в категорию одним кликом.
- Голос: кнопка микрофона → Whisper → текстовый пайплайн.
- Крупный мазок: «Еда за неделю ~8000» — легитимный первоклассный сценарий, никакого чувства вины.

## Пересборка плана (модал)

Заголовок без драмы: «Еда закончится 21-го. Откуда добавим?»
Варианты отсортированы по истории PlanRevision:

1. «Из Прочего: там свободно 4k» (если делал так раньше — бейдж «как обычно»)
2. «Из конверта Инвестиции»
3. «У следующего периода (25-го свободных будет меньше на 3k)»
   Цели/конверты показывают последствие сразу: «отпуск отодвинется на 2 недели». Долги в списке отсутствуют. Подтверждение одним кликом, откат — из истории ревизий.

## Экран «Размен»

- План корзин на период + факт разменов.
- История: дата, суммы, мой курс vs официальный, спред %.
- Аналитика: «за 6 месяцев спред в среднем 1.8% = потеряно 240 EUR» — по провайдерам (тег обмена: менялы/банк/Wise).

## Экран «Обязательства» (долги/конверты/цели)

- Долги: карточки с прогрессом погашения и датой свободы; при закрытии — celebrаtion + «куда направить освободившиеся 8k?»
- Конверты: правило (10% с выплаты), баланс.
- Цели: прогресс, ETA в месяцах и зарплатах, «заморозить взнос на период» одной кнопкой.

## Аналитика

- План/факт по периодам (столбики), по категориям.
- Валютная картина: доля трат по валютам, динамика курсов моих пар, накопленный спред.
- Никаких pie-chart трат за всё время на старте — только вопросы, на которые есть действие.

## Пустые состояния и тон

Тон — штурман: «Курс на месяц проложен», «До цели 4 зарплаты». Никогда: «Вы превысили бюджет!», красный стыд, восклицательные нотации. Пропустил две недели → «Введи примерную сумму за пропущенное одним числом» — и живем дальше.
