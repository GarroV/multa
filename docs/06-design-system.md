# Multa — Дизайн-система «Neon Ledger»

Направление (решение основателя): неон, киберпанк. Интерпретация: **терминал штурмана в ночном городе** — темная база, дисциплинированный неон, данные как главный герой. Киберпанк — в атмосфере, не в хаосе: финансовый продукт обязан оставаться читаемым и спокойным.

## Принципы

1. Неон — только для смысла: акценты, состояния, ключевые цифры. Фоны и текст — тихие. Максимум 2 неоновых цвета в кадре одновременно.
2. Деньги = моноширинный шрифт, всегда табличное выравнивание цифр.
3. Никакого красного стыда: перерасход — это сигнал маршрута (магента), не ошибка пользователя.
4. Свечение (glow) — минимальное и функциональное: активные элементы и сигналы. Никаких мигающих анимаций.
5. Dark-only в MVP. Светлая тема — после (заложить через CSS-переменные).

## Токены

```css
:root {
  /* База */
  --bg-void:      #07090F;  /* фон приложения */
  --bg-panel:     #0D1220;  /* карточки, панели */
  --bg-raised:    #131A2E;  /* модалы, hover */
  --line:         #1E2A45;  /* границы, разделители, сетки графиков */

  /* Текст */
  --text-hi:      #EAF2FF;  /* заголовки, деньги */
  --text-mid:     #93A4C3;  /* вторичный */
  --text-dim:     #55648A;  /* подписи, disabled */

  /* Неон */
  --neon-cyan:    #00E5FF;  /* primary: действия, ссылки, активные состояния, герой-цифра */
  --neon-magenta: #FF2E97;  /* сигналы: burn-rate риск, перерасход */
  --neon-lime:    #B6FF2E;  /* позитив: доход, цель достигнута, долг закрыт */
  --neon-amber:   #FFB020;  /* предупреждения средней важности, спред */
  --neon-violet:  #8B5CF6;  /* валютные корзины и размен */

  /* Свечение */
  --glow-cyan:    0 0 12px rgba(0,229,255,.35);
  --glow-magenta: 0 0 12px rgba(255,46,151,.35);

  --radius: 12px;
  --radius-lg: 20px;
}
```

Семантика: `--accent = cyan`, `--danger = magenta`, `--success = lime`, `--warning = amber`, `--fx = violet`. В коде использовать только семантические имена.

## Типографика

- UI: **Geist** (кириллица обязательна), 14/16/18. _(Обновлено по макету `design/prototype.html`; ранее значился Inter.)_
- Деньги и цифры: **JetBrains Mono** — герой-цифра 48–64px medium, суммы в списках 16px, `font-variant-numeric: tabular-nums`.
- Заголовки: Geist SemiBold. Латинский герой/логотип-шрифт: Space Grotesk (бренд и крупные hero-заголовки лендинга).
- Никаких UPPERCASE-заголовков, кроме микролейблов 11px (letter-spacing 0.08em, --text-dim).

## Компоненты (ключевые)

- **HeroNumber**: цифра дня. JetBrains Mono, --text-hi, подсветка --glow-cyan только у изменившейся части («N/день»). Под ней — тихая подпись.
- **ProgressBar категории**: трек --line, заполнение градиент cyan→violet; риск-состояние: заполнение magenta + glow, справа «хватит до 21-го».
- **Card**: --bg-panel, радиус 12, граница 1px --line; hover — граница cyan/40%, без изменения фона.
- **Button primary**: заливка transparent, граница 1px --neon-cyan, текст cyan; hover: заливка cyan/10% + glow. Destructive — то же с magenta. Заливные кнопки не используем (неон = контур, terminal-вайб).
- **SignalBanner** (burn-rate): левая неоновая кромка 2px magenta, фон magenta/5%, текст спокойный: «Еда закончится 21-го» + кнопка «Пересобрать».
- **Timeline прогноза**: горизонтальная линия --line, события — неоновые точки (выплата lime, долг закрыт cyan, риск magenta), вертикальный курсор «сегодня» cyan.
- **Валютный бейдж**: моно, контурный: `EUR` violet, базовая валюта — без бейджа (она «воздух» системы).
- **Графики**: фон без заливки, сетка --line, линии cyan/violet/lime толщиной 2, glow на активной точке. Отрицательные значения — magenta.

## Motion

- Транзакция записана: короткая вспышка glow на строке (200ms ease-out).
- Числа меняются через count-up 300ms.
- Пересборка плана: суммы «перетекают» (translate + fade 250ms).
- prefers-reduced-motion — всё отключается.

## Доступность

Контраст: --text-hi на --bg-panel ≥ 12:1; неоновые тексты только ≥ 16px или полужирные; cyan на --bg-void = 10.9:1 ✓. Magenta/lime не единственный носитель смысла — всегда дублировать текстом/иконкой. Фокус-кольцо: 2px cyan, offset 2px, всегда видимо.

## Тон текстов (RU/EN)

Штурман, не учитель. «Курс проложен» / "Route set". «Еда закончится 21-го. Откуда добавим?» / "Food runs dry on the 21st. Where do we pull from?". Запрещено: «Вы превысили!», вина, восклицательные предупреждения, канцелярит.

## Лендинг

Тот же язык: черный фон, неоновая сетка-горизонт, герой-скриншот дашборда, один cyan-CTA. Слоган: «Бюджет, который переезжает с тобой» / "Budget across borders".
