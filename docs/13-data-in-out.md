# Multa — Данные: входы, выходы, сохранность

Принцип: пользователь никогда не заперт (данные легко унести) и никогда не наказан за ошибку (всё откатывается). Это часть бренда доверия наравне с privacy.

## Входы (кроме ручного/бота/чеков/банковских выгрузок)

### Миграция со своей Excel-таблицы ⭐ приоритет
Наша ЦА уже ведет таблицы (референсы: «Кетчуп в Химках» — планирование по полумесяцам; «Финмодель основная» — семейный позиционный учет 5000+ строк за 3,5 года). Онбординг-путь «у меня есть таблица»: загрузи xlsx → LLM распознает структуру (периоды, категории, долги, план/факт, позиции) → предпросмотр маппинга → перенос истории и плана. **Если в таблице есть словарь «продукт → категория» (как лист «Словарь» финмодели) — импортируем его как личный словарь автокатегоризации**: категоризация работает с первого дня без обучения. Два шаблона поддержать из коробки: «колонки-полумесяцы» и «журнал позиций (дата/категория/продукт/цена/кол-во)».

### Миграция из других приложений
Импорт CSV-экспортов Дзен-мани, CoinKeeper, Toshl, YNAB — готовые пресеты маппинга (их форматы публичны). Лендинг-страницы «переехать с X» под SEO «X alternative».

### Email-инбокс
Персональный адрес workspace (in-abc123@multa.app): пересылаешь квитанции Wise/Revolut/PayPal/брокера → парсер (сначала шаблоны, LLM-фоллбек) → транзакция на ревью. Закрывает сервисы, у которых нет SMS/пушей.

### Пересылка в бота
Forward банковской SMS/пуша в бота как текст → тот же парсер, что и свободный ввод, плюс словарь шаблонов банков. Ручной аналог Android-companion (см. ниже), работает на любой платформе уже в фазе бота.

### Авто-детект оплат (фаза 3)
Android-companion (NotificationListenerService — читает банковские пуши, шлет в API) + iOS Shortcut на триггер «Транзакция» Apple Pay → webhook. Ввод с нулевым усилием.

### Единый дедуп-движок
Все источники (ручной, бот, чек, импорт, email, SMS, авто-детект) проходят одну проверку: (дата ±1 день, сумма, валюта, счет) → кандидаты в дубли на ревью, слияние одним тапом, «это разные» запоминается. Без этого мультиканальный ввод превратится в двойной учет.

## Выходы

- **CSV/JSON полный экспорт** — из настроек, в любой момент (уже в MVP).
- **Автобэкап пользователю**: раз в неделю JSON-архив в личку бота или на email (опция). Доверие: «твои данные у тебя, даже если мы умрем».
- **Экспорт в Google Sheets** (live-sync, v2): для тех, кто хочет свои сводные поверх — не воюем с таблицами, дружим.
- **Налоговый экспорт фрилансера** ⭐ ниша: доходы за период с курсом ЦБ на дату каждого поступления — готовая таблица для декларации (RS paušal, GE ИП, РФ УСН). Мультивалютникам это больно делать руками — мы уже храним курс на дату.
- **Публичный API + вебхуки** (Pro, v2): токен workspace, POST /transactions и подписка на события — для Zapier/n8n/самоделок. Это же эндпоинт для iOS Shortcut.

### Отчеты (документы с выводами, не данные)
- **Отчет периода** — генерируется автоматически при закрытии периода: план/факт по категориям, исполнение раскладки, размены с курсами и спредом, движение долгов/целей. Одна страница. Приходит ссылкой в бот — ретеншн-точка закрытия периода.
- **Годовой отчет** («итоги года»): валюты, топ-категории, экономия на пересборках, путь целей. Полный документ + отдельная шарабельная карточка (анонимизированная, для соцсетей — виральный контур).
- **Отчет для партнера**: сводка периода без деталей трат («мы в плане, до отпуска 2,5 зарплаты») — мостик к семейному тарифу.
- Форматы: HTML-ссылка (живая) + PDF (хранить/печатать). Free — отчет периода; годовой и партнерский — Pro.

## Сохранность

- **Корзина**: удаленное (транзакции, категории, цели) живет 30 дней, восстанавливается одним тапом.
- **Журнал изменений для пользователя**: своя история правок (кто/что/когда — актуально для будущего семейного доступа), откат точечной правки.
- **Откат батчей**: импорт, распознанный чек с позициями, пересборка плана — атомарные группы, откатываются целиком.
- **Сверка остатков (reconciliation)**: раз в 2–4 недели мягкий вопрос «на счету X примерно 45 300 ₽?» [да] [ввести фактический] → расхождение фиксируется корректировкой с source='reconcile', не размазывается по истории. Возвращает доверие к цифрам — главную причину смерти учета.

## Приоритеты

MVP: экспорт CSV/JSON, корзина, откат батчей, сверка остатков.
Фаза 2 (с ботом): импорт банк-выгрузок, миграция с Excel, пересылка в бота, автобэкап.
Фаза 3: email-инбокс, миграции из приложений, Google Sheets, налоговый экспорт, API/вебхуки, авто-детект.
